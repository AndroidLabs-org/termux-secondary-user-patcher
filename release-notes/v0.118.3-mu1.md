## Termux Secondary User Patcher 0.118.3-mu1

Official Termux **v0.118.3** with the secondary-user patch set applied. This is the first release.

### What it does
Makes Termux (`com.termux`) start and run in Android secondary users, using a process-local bind
mount set up through Magisk. User 0 is unchanged and never asks for root.

### Before you install
- Clean install, no data migration. Uninstall official Termux and its plugins in every user first (official plugins cannot be installed next to this build, see Plugins).
- Magisk, with **Multiuser Mode = User-Independent or Device Owner Managed** (the default, Device Owner Only,
  blocks every secondary user) and **Mount Namespace Mode = Inherit Namespace**. See the README.
- Pick the APK for your device (`arm64-v8a` for almost every phone).

### Tested
- Release build, signature and certificate fingerprint.
- Real device (Google Pixel 8a, Android 17, Magisk 31.1, 18 Nov 2026, test build): secondary users
  10 and 11 (also at once), `TERMUX__USER_ID`, `pkg update` and package install, storage setup,
  Device Owner Managed and User-Independent modes; user 0 normal, no root request.
- Emulator (Android 14, Magisk 26.4): root mapping, user 0, and a secondary user without root
  (clear setup screen, clean refusal, no crash).

### Not tested yet
- KernelSU/APatch, work profiles, cold `RUN_COMMAND`, other devices and Android versions.
- Magisk 31.1 has no interactive root prompt: grant Termux root in the Superuser tab first (see the README).

### Plugins
Not supported in secondary users in this release. Six official plugins were tested in a secondary user on an emulator and only Termux:Styling works. No plugin is shipped. See the README, section Plugins.

### Known limitations
See the README: the mapping lasts as long as the Termux process, the first launch can wait for the
Magisk prompt, and `targetSdk 28` is inherited from upstream.

Verify the download with `SHA256SUMS.txt`, `gh attestation verify` and the certificate fingerprint in
the README.
